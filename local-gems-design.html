Behavior notes

  • Anchoring: group day.wishlist by gem.near ↔ activity title (trimmed, case-insensitive). Matched → inline row after that activity; unmatched → Also-nearby strip. Max 2 inline per activity, extras behind “＋N more nearby”. no migration
  • Add: verify-place ladder (non-blocking on failure) → insert activities row (type sight, 45m, untimed, icon ✨, position anchor+0.5) → mark gem dismissed+promoted → system-undo chat message. Replaces today's chat-delegated add.
  • Row actions: + Add is the one visible action; everything else lives behind ⋯ — Tell me more (opens Trippy chat pre-sent with “Tell me more about {gem} near {anchor}” — existing Ask Trippy path), Open in Maps, and Dismiss (unchanged dismissGemPersist + undo). Row body tap also opens Maps.
  • Suggestion, not itinerary: gem rows are sand-tinted with a dashed gold border and hang off the rail by a stub connector — visually subordinate to activity cards.
  • Dedupe guard: a gem whose title already exists as an activity in the day is hidden.
  • Rides along: dismissed-gem leak fixed in deep-dive roll-up + brainstorm highlights; dead compact-count code deleted; the old 4-item GemCard menu shrinks to this 3-item one (Add promoted out of it).
  • Prompt nudge: generate-itinerary near rule tightened to “verbatim title from THIS day, else the gem is demoted”.
