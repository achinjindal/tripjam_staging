2 · Mid-trip legs show up on their day

Trips carry 3–4+ legs — internal trains and hops, not just arrival and departure. A booked leg renders on the itinerary day it happens (matched by date): as a ✓ Booked badge on a matching transit activity when one exists, else as a pinned strip at the top of the day. Derived at render time from travel_data — never inserted into activities, so day regenerates can't touch it.

Behavior notes

  • Global trains: parser is operator-agnostic — Amtrak, Eurostar, DB/ICE, SNCF/TGV, Trenitalia, JR, IRCTC, Via Rail. Operator, train number/name, stations and class are kept verbatim from the ticket; vendor quirks (IRCTC 10-digit PNR, Eurostar 6-char refs) are prompt hints, not code paths.
  • Data: one additive migration — trips.travel_data jsonb, array of legs {kind, carrier, number, date, depart_time, arrive_time, from, to, confirmation, class, status, via}. Same pattern as hotels_data.
  • Dedupe/update: leg key = confirmation, else (kind, number, date). Re-forwards and reschedules update in place; cancellations flip status but keep the row.
  • Boundary auto-fill: a booked leg on start_date/end_date fills the arrival/departure editors — only with genuinely parsed times, never overwriting user-typed values.
  • Upload parsing: dry_run gains a file input (image or PDF, base64 ≤4 MB, client downscales screenshots); Haiku reads it with the same parse contract and returns leg_preview. Shares the existing 30/user/day meter.
  • Apply is client-side: “Add to trip” writes via the user's own session (RLS) with via:"upload". No new endpoint, no new auth surface.
  • Affiliate (Part D, ships dark): “Compare flights ↗” on unbooked boundaries only, link template from VITE_FLIGHT_LINK_PREFIX (Travelpayouts recommended — Aviasales/WayAway ~1.1–1.3%, Kiwi ~3%). Never shown on booked legs.
  • Copy honesty rides along: teaching card + send-email footer change “hotel confirmations” → “hotel, flight or train confirmations” in the same release.
  • Dropped: paste-text input (niche — screenshots cover it); wrong-trip move UI (the sheet targets the open trip via its plus-address).
